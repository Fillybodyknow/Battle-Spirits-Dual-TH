# เนื้อเรื่อง "ยุคสมัยแห่งเซ็นโงคุ" (โหมด SOLO · STORIES)

เอกสารหลักของเนื้อเรื่อง: อ่านก่อนเขียนบทใหม่ทุกครั้ง แล้วอัปเดตส่วน "สถานะ" เมื่อเขียนบทเสร็จ
ข้อมูลที่เล่นได้จริงอยู่ใน `apps/web/src/solo/gates.ts` (`SENGOKU_GATES`) · วิธีเขียนด่าน/กลไกดูหัวไฟล์นั้นและ CLAUDE.md หัวข้อ "โหมด SOLO"

## ข้อตกลงกับเจ้าของโปรเจกต์

- **Claude ร่างบทพูดเอง** แล้วเจ้าของโปรเจกต์ตรวจ/แก้ (บอกเจ้าของโปรเจกต์ทุกครั้งว่าแต่งอะไรเพิ่ม)
- เนื้อเรื่องแต่งเองทั้งหมด: ใช้ตัวละครจากการ์ดที่มีในเกม แต่ไม่ลอกเนื้อเรื่องจากอนิเมะ/เกมอื่น
- **เล่นแคว้นไหนก่อนก็ได้** (ทั้ง 6 แคว้นเปิดพร้อมกัน) · บทสุดท้ายเปิดเมื่อได้ตราแคว้นครบ 6
- ชื่อที่เจ้าของโปรเจกต์กำหนด: แคว้นสีขาว = **ปราการเหล็ก** (ไม่ใช่ "ป้อมเหล็ก")
- ข้อความภาษาไทยทั้งหมด

## โลกและโครงเรื่องรวม

ยุคสมัยแห่งเซ็นโงคุ แผ่นดินแตกเป็นหกแคว้นตามสีทั้งหก แต่ละแคว้นมี **ผู้เป็นนาย** ปกครอง และ **ขุนศึกรุ่นใหม่** (หกขุนศึกเซ็นโงคุ) ที่หมายจะโค่นบัลลังก์

- **ผู้เล่น = นักดวลพเนจร** ที่เดินทางไปทีละแคว้น พิสูจน์ตัวเองจนผู้เป็นนายยอมรับและมอบ **ตราแคว้น**
- มีเสียงเล่าลือว่าผู้ที่รวบรวมตราแคว้นได้ครบทั้งหก จะได้ยืนอยู่ ณ ใจกลางสงครามครั้งสุดท้าย
- **ปมหลัก: เงาสีรุ้ง** พาดผ่านฟ้าของทุกแคว้น สีทั้งหกกำลังถูกบางสิ่งดูดกลืนไปทีละสี
  ผู้เป็นนายแต่ละแคว้นพูดถึงมันตอนมอบตรา (ค่อย ๆ เผยทีละนิด ห้ามเฉลยตัวตนก่อนบทสุดท้าย)
- **ความจริง (เฉลยในบทสุดท้าย):** เงาสีรุ้งคือ **จอมมารสวรรค์ ก็อด-เซคส์** การ์ด 6 สี ผู้ดูดพลังของทั้งหกแคว้น
- **บทสุดท้าย "สงครามแห่งเซ็นโกคุ":** ขุนศึกทั้งหกที่ถูกจอมมารครอบงำ → ก็อด-เซคส์ → ร่างที่แข็งแกร่งขึ้น

## หกแคว้น

| id | แคว้น | สี · เผ่า | ตราแคว้น | ขุนศึกรุ่นใหม่ | ผู้เป็นนาย (บอส) | การ์ดเด่นอื่น ๆ |
|---|---|---|---|---|---|---|
| `sengoku-red` | แคว้นเปลวเพลิง | แดง · มังกรยุทธ์ / เจ้าสมิง | ตราแห่งเพลิง | หกขุนศึกเซ็นโงคุ **เลออนแลนเซอร์** (BS34-XCP07) | จักรพรรดิมังกรเซ็นโงคุ **เบิร์นนิ่ง-โซลดราก้อน** / จอมราชันเซ็นโงคุ **กิวมอนจิ** | โซลดราก้อน, ราโอว, กุเร็นดราก้อน, ซีคฟรีด |
| `sengoku-green` | ป่าวายุ | เขียว · วายุนินจา / ศาสตราสมิง | ตราแห่งวายุ | หกขุนศึกเซ็นโงคุ **เทนเซย์** | สมิงไดเมียว **ไยบะโนะคามิ** | ชิโนบิริกะ, โทวโดว, คุวากะสเลเยอร์, คิริคาเงะ, ชิโนบิโอว |
| `sengoku-white` | ปราการเหล็ก | ขาว · เครื่องกล | ตราแห่งเหล็ก | หกขุนศึกเซ็นโงคุ **เซ็นริวดาคุ** | จอมทัพใหญ่จักรกล **ไทคูน** | คองโก, เดย์เบรค-เธิร์ด |
| `sengoku-yellow` | ปราสาทเจ้าหญิง | เหลือง · เจ้าหญิงสงคราม / โยวไค | ตราแห่งแสง | หกขุนศึกเซ็นโงคุ **บาเครุคัทซึ** | แม่ทัพโยวไค **คาฉะเนโกะ-อิคุสะ** | เซ็นโงคุฮิเมะ (มาคินะ, นายูทะ, มิโคโตะ…), ดีว่า / On Stage |
| `sengoku-purple` | แดนต้องสาป | ม่วง · มารต้องสาป / อสูรราตรี | ตราแห่งเงา | หกขุนศึกเซ็นโงคุ **มุโดว** | ราชาวิญญาณเทพ **อาเมะโอชิโนะมิโคโตะ** | จักรพรรดิองเมียว ริคุโดว, เทพยักษ์บาซาระ |
| `sengoku-blue` | ทะเลวิญญาณ | ฟ้า · วิญญาณนักรบ / สมิงหัว | ตราแห่งสมุทร | หกขุนศึกเซ็นโงคุ **ไทดัล-บลู** | ไดเมียวเจ็ดดาบสมุทร **ชิโรนากัส** | ฮะไดเมียวโอ เนอวาน่า, ราชันดอกบัว เซ็นจู |

บทสุดท้าย `sengoku-war` · **สงครามแห่งเซ็นโกคุ** · บอส: จอมมารสวรรค์ ก็อด-เซคส์ (SD32-X02), -รูปแบบที่ศูนย์- (BS34-U016), **-รูปแบบทำลายล้าง-** (BS34-XX02) · การ์ด "จุติจอมมารสวรรค์" (BS34-C075)

## เด็ค

- เด็คประจำแคว้น 3–4 เด็คต่อบท: **เด็คยืม** (เผ่าหลักของแคว้น) · เด็คหัวหน้ากลุ่มย่อย · เด็คขุนศึก · เด็คผู้เป็นนาย
- ใช้การ์ดที่มีภาพแล้วเท่านั้น (`assets/images/cards`) · ชื่อเดียวกันไม่เกิน 3 ใบ · 40 ใบ
- ตรวจก่อนส่ง: `validateDeck` ผ่าน + บอทเล่นกันเองจนจบไม่มี fallback (ดู `packages/engine/test/bot-helpers.ts`)
- ความยากของด่านมาจากดาวของบอทเป็นหลัก (เด็คแต่ละเด็คควรแรงพอ ๆ กันที่ ★5)

## เขียนบทใหม่: ขั้นตอน

1. อ่านเอกสารนี้ + บทป่าวายุใน `gates.ts` เป็นแม่แบบ
2. จัดเด็ค (ด้วย `deck(...)` ใน gates.ts) แล้วตรวจตามหัวข้อ "เด็ค"
3. แทน `soon(...)` ของแคว้นนั้นด้วย object บทเต็ม (คง `id` / `emblem` เดิม: ความคืบหน้าผู้เล่นผูกกับ id)
4. เปิดดูในเบราว์เซอร์ (หน้า Stories + แผนที่ + แผงด่าน) · typecheck / เทสต์ / build
5. อัปเดตตาราง "สถานะ" ในเอกสารนี้ + changelog แล้วให้เจ้าของโปรเจกต์ดูบทพูด
