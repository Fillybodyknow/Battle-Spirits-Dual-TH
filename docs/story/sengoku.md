# เนื้อเรื่อง "ยุคสมัยแห่งเซ็นโงคุ" (โหมด SOLO · STORIES)

เอกสารหลักของเนื้อเรื่อง: อ่านก่อนเขียนบทใหม่ทุกครั้ง แล้วอัปเดตส่วน "สถานะ" เมื่อเขียนบทเสร็จ
ข้อมูลที่เล่นได้จริงอยู่ใน `apps/web/src/solo/gates.ts` (`SENGOKU_GATES`) · วิธีเขียนด่าน/กลไกดูหัวไฟล์นั้นและ CLAUDE.md หัวข้อ "โหมด SOLO"

## ข้อตกลงกับเจ้าของโปรเจกต์

- **Claude ร่างบทพูดเอง** แล้วเจ้าของโปรเจกต์ตรวจ/แก้ (บอกเจ้าของโปรเจกต์ทุกครั้งว่าแต่งอะไรเพิ่ม)
- เนื้อเรื่องแต่งเองทั้งหมด: ใช้ตัวละครจากการ์ดที่มีในเกม แต่ไม่ลอกเนื้อเรื่องจากอนิเมะ/เกมอื่น
- **โทน: สงคราม · Dark Fantasy · เซ็นโงคุ** (เจ้าของโปรเจกต์กำหนด) ดูหัวข้อ "โทนเรื่อง"
- **แต่ละบทต้องมีเส้นทางและวิธีเล่าเรื่องไม่ซ้ำกัน** มีด่านที่เป็นบทสนทนาล้วนคั่น ให้ Timeline หลากหลาย (ดู "รูปแบบของแต่ละบท")
- **เล่นแคว้นไหนก่อนก็ได้** (ทั้ง 6 แคว้นเปิดพร้อมกัน) · บทสุดท้ายเปิดเมื่อได้ตราแคว้นครบ 6
- ชื่อที่เจ้าของโปรเจกต์กำหนด: แคว้นสีขาว = **ปราการเหล็ก** (ไม่ใช่ "ป้อมเหล็ก")
- ข้อความภาษาไทยทั้งหมด
- เขียนบทใหม่/เขียนทับบทเดิมได้โดยไม่ต้องคงความคืบหน้า (ป่าวายุเขียนใหม่แล้วล้างความคืบหน้าเดิม: id โหนดที่ไม่มีแล้วถูกทิ้งตอนโหลดใน `solo/progress.ts`)

## โทนเรื่อง

- **สงคราม:** แผ่นดินเป็นสนามรบที่ไม่เคยสงบ ธงขาด ปราสาทร้าง หมู่บ้านที่ถูกเผา ทุกแคว้นมีความสูญเสียของตัวเอง ทุกชัยชนะมีราคา
- **Dark Fantasy:** ภัยที่ใหญ่กว่าสงครามคือ "ความเทา" ที่กลืนทั้งผืนดินและผู้คนอย่างเงียบ ๆ คำสาป การครอบงำ เสียงกระซิบ คนที่รักสิ่งเดียวกันแต่เลือกทางต่างกันจนต้องฆ่ากัน
- **เซ็นโงคุ:** ผู้เป็นนาย ขุนศึก ข้ารับใช้ เกียรติ ความภักดี การทรยศ
- ขอบเขต: มืดแบบความสูญเสีย การทรยศ การตัดสินใจที่ไม่มีทางถูก ไม่บรรยายความรุนแรงโจ่งแจ้ง (ไม่มีเลือดสาด ศพถูกบรรยายเป็น "สีเทา/เถ้า")
- ผู้เล่นไม่ใช่วีรบุรุษตั้งแต่ต้น: เป็นคนนอกที่แต่ละแคว้นไม่ไว้ใจ ต้องพิสูจน์ด้วยการดวล
- ตัวละครฝ่ายตรงข้ามมีเหตุผลของตัวเองเสมอ (เทนเซย์อยากเผาป่าเพราะรักป่า ไม่ใช่เพราะชั่ว)

## โลกและโครงเรื่องรวม

ยุคสมัยแห่งเซ็นโงคุ สงครามยาวนานจนไม่มีใครจำได้ว่าเริ่มเมื่อใด แผ่นดินแตกเป็นหกแคว้นตามสีทั้งหก แต่ละแคว้นมี **ผู้เป็นนาย** ปกครอง และ **ขุนศึกรุ่นใหม่** (หกขุนศึกเซ็นโงคุ) ที่หมายจะโค่นบัลลังก์

- **ผู้เล่น = นักดวลพเนจร** เดินทางไปทีละแคว้น ได้ **ตราแคว้น** เมื่อแคว้นนั้นยอมรับ (ใครเป็นคนมอบขึ้นกับเรื่องของบทนั้น)
- **ปมหลัก: เงาสีรุ้ง** พาดผ่านฟ้าของทุกแคว้น ที่ที่มันทอดผ่าน **สีหายไปจากผืนดิน เหลือแต่ความเทาที่ไร้ลมหายใจ** (คน สปิริต ต้นไม้ หยุดนิ่งเป็นสีเถ้า)
  เงานี้ **กระซิบเรียก** ผู้ที่อ่อนแอหรือหมดหวัง สัญญาว่าจะช่วย แล้วกลืนจากข้างใน (คนที่ถูกกลืนมีผิวเป็นสีเทาลามขึ้นทีละน้อย)
  ค่อย ๆ เผยทีละบท ห้ามเฉลยตัวตนก่อนบทสุดท้าย · บทที่จบแล้วบอกใบ้ได้ว่า "มันรู้จักเจ้าแล้ว"
- **ความจริง (เฉลยในบทสุดท้าย):** เงาสีรุ้งคือ **จอมมารสวรรค์ ก็อด-เซคส์** การ์ด 6 สี ผู้ดูดสีของทั้งหกแคว้น
- **บทสุดท้าย "สงครามแห่งเซ็นโกคุ":** ขุนศึก/ผู้เป็นนายที่ถูกกลืน → ก็อด-เซคส์ → ร่างที่แข็งแกร่งขึ้น

## รูปแบบของแต่ละบท (ไม่ซ้ำกัน)

แต่ละบทเลือก **รูปทรงเส้นทาง + วิธีเล่าเรื่อง + แก่นเรื่อง** ของตัวเอง ห้ามใช้โครงเดียวกันซ้ำ (แผนด้านล่างเป็นร่าง ปรับได้ตอนเขียนจริง)

| บท | รูปทรงเส้นทาง | วิธีเล่าเรื่อง | แก่นเรื่อง |
|---|---|---|---|
| **ป่าวายุ** (เขียว) ✅ | **ทางแยกให้เลือก** (`afterAny`): เหนือ = เผชิญนักล่า / ใต้ = ทางเงา (ทั้งสองทางมีดวล) → รวมที่ศาลเจ้า · ผู้เป็นนายถูกกลืนเป็นบอสกลางเรื่อง · ทางเสริมหลังได้ตรา (★5 → ★6) | ไล่ล่า เดินหน้าตลอด เผยทีละชั้นว่าใครคือศัตรูตัวจริง | ผู้นำที่รอ vs ผู้นำที่ยอมเผาทุกอย่าง · ใครปกป้องป่าได้จริง |
| **แคว้นเปลวเพลิง** (แดง) ✅ | **สองเส้นสลับอดีต/ปัจจุบัน**: แถวล่าง = ปัจจุบัน (มาถึงหลังไฟดับ 7 วัน) แถวบน = ความทรงจำ (ฉาก "ความทรงจำ: ...") สลับกันจนบรรจบที่แถวกลาง → พิพากษา (กิวมอนจิ ★4) → ตรา · ทางเสริม: เลออนแลนเซอร์ ★5 (ปัจจุบัน) → ความฝันถึงจักรพรรดิมังกร ★6 (อดีต) | **เล่าย้อน (flashback)**: ฮิรินมารุผู้รอดชีวิตพาตามหาความจริง · ความทรงจำค่อย ๆ เผยว่าจักรพรรดิมังกรถูกเงากลืนและสั่งให้จุดไฟเอง | ราคาของชัยชนะ · ความผิดที่ต้องแบกแทนผู้อื่น · กฎกับความจริง |
| **ปราการเหล็ก** (ขาว) | **ตั้งรับหลายคืน**: ด่านเรียงตาม "คืนที่ 1 / 2 / 3" แต่ละคืนต้องรักษาสองกำแพง (ต้องผ่านทั้งคู่: `after` สองโหนด) | **นับเวลาถอยหลัง** ผู้เล่นอยู่ฝั่งเมืองที่ถูกล้อม บทสนทนาคั่นระหว่างคืน (คนในเมืองค่อย ๆ หมดหวัง) | จักรกลที่ไม่รู้จักความกลัว vs คนที่กลัว · ไทคูนต้องเลือกระหว่างกำแพงกับคนในเมือง |
| **ปราสาทเจ้าหญิง** (เหลือง) | **เลือกฝ่าย**: ทางแยกเจ้าหญิง / แม่ทัพ (`afterAny`) แต่ละทางมีฉากของตัวเอง แล้วบรรจบที่ "คืนแห่งการทรยศ" | **ราชสำนักและการแสดง**: งานเลี้ยง เวที (ดีว่า / On Stage) จดหมายลับ คำพูดที่ไม่ตรงกับใจ | การแสดงที่ปกปิดการลอบสังหาร · ไม่มีใครพูดความจริง |
| **แดนต้องสาป** (ม่วง) | **ดิ่งลง**: เส้นตรงยาว บทสนทนาหนาแน่น ดวลน้อย มีโหนดกั้น (`locked`) ที่เปิดเมื่ออ่านความทรงจำครบ | **ผู้เล่าที่เชื่อไม่ได้**: เสียงกระซิบ (ผู้พูด "???") ความทรงจำที่ขัดกันเอง · ดวลกับ "เงาของตัวเอง" (เด็คเดียวกับเด็คยืม) | ความตายและการลืม · ใครกันแน่ที่ถูกสาป |
| **ทะเลวิญญาณ** (ฟ้า) | **ศูนย์กลางและเกาะ**: ท่าเรือกลาง → สามเกาะเล่นลำดับไหนก็ได้ (3 แถว) → ต้องผ่านครบจึงออกทะเลลึก · มีเกาะเสริม | **บันทึกเดินเรือ**: บทบรรยายเป็นรายวันของการเดินทาง | ทะเลที่เก็บวิญญาณผู้ตายในสงคราม · การปล่อยวาง |
| **สงครามแห่งเซ็นโกคุ** | **แนวรบ**: กำแพงขุนศึกที่ถูกกลืน (3 แถว × 2) ต้องผ่านครบ → ก็อด-เซคส์ 3 ร่าง | **หลายมุมมอง**: ฉากคั่นจากมุมของจอมมาร (ผู้พูด = ก็อด-เซคส์) และของผู้เป็นนายที่ผู้เล่นเคยช่วย | การรวมหกสีที่แตกแยก |

### ชนิดโหนดที่ใช้ได้ (ดูหัวไฟล์ `gates.ts`)

- `scenario` = **ด่านบทสนทนาล้วน** วางคั่นได้ทุกที่ (เปิดบท, ระหว่างดวล, หลังดวล, ตอนจบของทางเสริม)
- `practice` (บทเรียนสอนเด็ค `lesson`) · `duel` (★1–6) · `goal` (ได้ตรา: บทผ่านเมื่อ goal ทุกตัวผ่าน) · `locked` (โหนดกั้น)
- แผนที่ **2 หรือ 3 แถว** (`row` 0–2) · `after` = ต้องผ่านทุกโหนด · `afterAny` = **ทางแยกให้เลือก** (ผ่านทางไหนก็ไปต่อได้; ทางที่ไม่ได้เลือกยังกลับไปเล่นได้ แต่ป้าย "ถัดไป" ข้าม)
- โหนดที่ไม่มีใครต่อจาก = ทางเสริม (ไม่กระทบตรา)

### ข้อกำหนดเดิมที่ยังใช้

- ทุกบทมีบทเรียนฝึกเด็ค ★1 และดวลระดับ ★5–6 อย่างน้อยหนึ่งด่าน (ในเรื่องหลักหรือทางเสริม)
- ทุกโหนดดวลมี `opponent`, `avatar` (รหัสการ์ดของคู่แข่ง = รูปโปรไฟล์บอท + พื้นหลังโหนด), `description` (แผงด่าน), `deckDescription` (หน้าดูเด็คคู่แข่ง)
- บทพูด: 4–6 กล่องต่อฉาก (ฉากสำคัญได้ถึง 7) · ผู้พูด = ชื่อการ์ดเต็ม (เช่น "สมิงไดเมียว ไยบะโนะคามิ") · บรรยายไม่ใส่ผู้พูด · ได้ตรา = กล่องบรรยาย `ได้รับ "ตรา..."`
- ฉากเปิดของแต่ละแคว้นไม่ควรพึ่งว่าผู้เล่นเล่นแคว้นอื่นมาก่อน · บรรยายยุคซ้ำได้สั้น ๆ

ใช้ตัวรันเดียวกับ TUTORIAL (`tutorial/tutorial.ts`): จัดสนามด้วย `setup()` · ขั้น = ข้อความ + จุดส่องไฟ + action ที่รอ (รูปแบบขั้นดูหัวไฟล์ `tutorial/lessons.ts`)

- โครงที่ใช้ (ป่าวายุ `wind-ninja`): แนะนำเด็ค → ลูกเล่นทีละอย่าง (2–3 อย่าง) ให้ผู้เล่นลงมือเอง → ขั้นสุดท้ายเล่นอิสระปิดเกม → สรุปลูกเล่น + การ์ดเด่นอื่นในเด็ค
- จัดสถานการณ์ให้ชนะได้ใน 1 เทิร์นด้วยลูกเล่นที่สอน (คู่แข่ง Life น้อย · `bot` ของบทกำหนดการป้องกันให้ผู้เล่นต้องใช้ลูกเล่น)
- ใช้การ์ดที่ engine ไม่ถามตัวเลือกแปลก ๆ ระหว่างบท · ทดสอบเดินครบทุกขั้นในเบราว์เซอร์ (จบ = โหนดผ่าน + ปุ่ม "กลับไปที่ด่าน")
- ป่าวายุสอน: โซลคอร์บนนินจา (ฮ็อปปะ BP+3000 / ชิโนบิริกะ) · คอร์วอยด์ (ทคคุริวอสพ์) · ทำให้คู่แข่งเสื่อมสภาพ (ปลดปล่อยพสุธา) · ฟื้นสภาพแล้วโจมตีซ้ำ (เคลื่อนย้ายในพริบตา)
- แคว้นเปลวเพลิงสอน (`war-dragon`): True-Rage บังคับป้องกัน (ชิปปูดราก้อน) · โซลคอร์ปลุกเอฟเฟกต์มังกร (ฮิรินมารุ Lv2 ทำลายเน็กซัส + ตัวป้องกัน)
- ข้อควรรู้ของตัวรันบท: ขั้นที่มี `expect` รับ action ได้ครั้งเดียว (เลือกเป้าสองครั้ง = สองขั้น) · มือไม่มีการ์ด Flash = ระบบผ่าน Flash ให้อัตโนมัติ การต่อสู้จบในคำสั่งเดียว อย่าทำขั้นรอปุ่ม PASS

## เด็ค

- เด็คประจำแคว้น 3–4 เด็คต่อบท: **เด็คยืม** (เผ่าหลักของแคว้น) · เด็คหัวหน้ากลุ่มย่อย · เด็คขุนศึก · เด็คผู้เป็นนาย (ใช้ซ้ำได้หลายด่าน: เช่น ร่างที่ถูกกลืนใช้เด็คยืม)
- ใช้การ์ดที่มีภาพแล้วเท่านั้น (`assets/images/cards`) · ชื่อเดียวกันไม่เกิน 3 ใบ · 40 ใบ
- ตรวจก่อนส่ง: `validateDeck` ผ่าน + บอทเล่นกันเองจนจบไม่มี fallback (ดู `packages/engine/test/bot-helpers.ts`)
- ความยากของด่านมาจากดาวของบอทเป็นหลัก (เด็คแต่ละเด็คควรแรงพอ ๆ กันที่ ★5)

## เขียนบทใหม่: ขั้นตอน

1. อ่านเอกสารนี้ (โทน + รูปแบบของบทนั้นในตาราง) + บทป่าวายุใน `gates.ts` เป็นตัวอย่างการเขียน (ไม่ใช่โครงที่ต้องลอก)
2. จัดเด็ค (ด้วย `deck(...)` ใน gates.ts) แล้วตรวจตามหัวข้อ "เด็ค"
3. แทน `soon(...)` ของแคว้นนั้นด้วย object บทเต็ม (คง `id` / `emblem` ของบท: ตราแคว้นและเงื่อนไขบทสุดท้ายผูกกับ id บท)
4. เปิดดูในเบราว์เซอร์ (หน้า Stories + แผนที่ + แผงด่าน + อ่านฉาก) · typecheck / เทสต์ / build
5. อัปเดตตาราง "สถานะ" ในเอกสารนี้ + changelog แล้วให้เจ้าของโปรเจกต์ดูบทพูด
