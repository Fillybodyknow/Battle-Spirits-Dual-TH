ว่าด้วยเรื่อง โหมด 2VS2 (กติกาของโปรเจกต์นี้)

โหมดทีม 2 คน ปะทะ 2 คน ไม่ใช่กติกาทางการของเกม เจ้าของโปรเจกต์กำหนดเอง
ข้อที่เขียนว่า (ร่าง) = Claude เสนอ ยังไม่ได้ยืนยัน · ข้อที่ไม่ได้เขียนไว้ = ใช้กติกา 1VS1 ปกติ (ไฟล์ 01–14)

1. ผู้เล่นและทีม
- ทีม A 2 คน, ทีม B 2 คน · แต่ละคนใช้เด็คของตัวเอง (เด็คปกติ ≥40 ใบ)
- เพื่อนร่วมทีมเห็นการ์ดในมือของกันและกัน · คู่แข่งเห็นแค่จำนวนใบ

2. สนามและความเป็นเจ้าของ
- สนามแสดงร่วมกันเป็นของทีม แต่การ์ดทุกใบมี "เจ้าของ" คือคนที่นำการ์ดนั้นลงสนาม
- ไลฟ์ รีเสิร์ฟ แทรช (การ์ดและคอร์) เด็ค เบิร์ส มือ แยกของใครของมัน · โซลคอร์คนละ 1 เม็ด
- จัดคอร์ (เพิ่ม/ลด Lv, ย้ายคอร์) ได้เฉพาะบนการ์ดของตัวเอง
- คอร์บนการ์ดเป็นของเจ้าของการ์ด · ออกจากสนามแล้วไปรีเสิร์ฟ/แทรชของเจ้าของการ์ดนั้น
- การ์ดที่ออกจากสนามไปแทรช/มือ/เด็คของเจ้าของการ์ด
- จ่ายคอสต์ด้วยคอร์ในรีเสิร์ฟของตัวเอง และคอร์บนการ์ดของตัวเองเท่านั้น

3. เทิร์น (สองคนในทีมเล่นพร้อมกัน)
- เทิร์นเป็นของทีม: เทิร์นทีม A → เทิร์นทีม B → … สลับกัน
- สตาร์ทสเต็ป / คอร์สเต็ป / ดรอว์สเต็ป: ทั้งสองคนในทีมได้คอร์ +1 และจั่วการ์ดของตัวเอง
- รีเฟรชสเต็ป: ฟื้นสภาพการ์ดบนสนามทั้งทีม และคอร์ในแทรชของทั้งสองคนกลับรีเสิร์ฟของแต่ละคน
- เมนสเต็ป: ทั้งสองคนอัญเชิญ ใช้เมจิค เซ็ทเบิร์ส จัดคอร์ของตัวเองได้อิสระ ไม่ต้องรอกัน
  (ระหว่างที่เอฟเฟกต์ของคนหนึ่งกำลังทำงาน/รอเลือก อีกคนต้องรอจนจบก่อน)
  จบเมนสเต็ปเมื่อทั้งสองคนกด "พร้อม"
- แอทแท็คสเต็ป: โจมตีทีละตัวเหมือนเดิม คนไหนในทีมประกาศก่อนก็ได้ · จบเมื่อทั้งสองคนกดจบ
- ทีมที่เริ่มเกม โจมตีไม่ได้ในเทิร์นแรก (เหมือน 1VS1)

4. การโจมตีและป้องกัน
- โจมตีได้เฉพาะสปิริต/อัลติเมทของตัวเอง (โจมตีด้วยของเพื่อนไม่ได้)
- ป้องกันด้วยสปิริต/อัลติเมทของใครในทีมก็ได้ · คนที่กดเลือกผู้ป้องกันต้องเป็นเจ้าของตัวนั้น
- ไม่ป้องกัน = ทั้งสองคนต้องโหวต "ไม่ป้องกัน" · คนใดคนหนึ่งประกาศป้องกัน = ทีมป้องกัน (โหวตที่ค้างอยู่ถูกล้าง)
- โจมตีไม่ถูกป้องกัน: ไลฟ์ของคู่แข่ง "ทั้งสองคน" ลดพร้อมกันตามจำนวนเจ็ม (คอร์ไลฟ์ไปรีเสิร์ฟของแต่ละคน)
  คนที่ไลฟ์ไม่พอ เสียเท่าที่มี

5. แฟลช
- ทั้งสองคนในทีมใช้ Flash จากมือได้ (จ่ายด้วยคอร์ของตัวเอง) และเอฟเฟกต์ Flash ของการ์ดบนสนามของตัวเอง
- (ร่าง) ลำดับสิทธิ์ตามกติกา 02 ระหว่างทีม · ในทีมเดียวกัน ทั้งสองคนต้องกดผ่านจึงนับว่าทีมนั้นผ่าน
  ผ่านติดกันทั้งสองทีม = จบช่วงแฟลช

6. เบรฟ
- เบรฟของเรา ร่วมร่างกับสปิริตของเพื่อนได้ (สปิริตยังเป็นของเพื่อน เพื่อนเป็นคนโจมตี/จัดคอร์)
- สปิริตของเพื่อนที่ร่วมร่างอยู่ออกจากสนาม: เจ้าของเบรฟ (เรา) เลือกว่าจะให้เบรฟอยู่ต่อไหม
  อยู่ต่อ = วางคอร์จากรีเสิร์ฟของเรา แล้วเบรฟลงมาเป็นสปิริตบนฝั่งของเรา · ไม่อยู่ต่อ = เบรฟลงแทรชของเรา
  คอร์ที่เคยอยู่บนสปิริตนั้นกลับรีเสิร์ฟของเพื่อน (เจ้าของสปิริต ตามข้อ 2)
- (ร่าง) แยกเบรฟออกจากร่างในเมนสเต็ป = เจ้าของเบรฟเป็นคนสั่ง

7. แพ้ชนะ
- ทีมแพ้เมื่อไลฟ์ของทั้งสองคนเป็น 0 หรือเด็คหมดทั้งสองคน
- คนที่ไลฟ์ 0 ยังเล่นต่อได้ตามปกติ · คนที่เด็คหมดยังเล่นต่อได้ แต่จั่วไม่ได้
- ไลฟ์เริ่มต้นคนละ 5 · รีเสิร์ฟเริ่มต้นและมือเริ่มต้นเหมือน 1VS1 ต่อคน

8. ความหมายของคำในเอฟเฟกต์
- "สปิริต/อัลติเมท/เน็กซัส ของเรา" = การ์ดบนสนามทั้งทีม (รวมของเพื่อน) เช่น BP+ ให้สปิริตของเพื่อนได้
- "ไลฟ์ / มือ / เด็ค / รีเสิร์ฟ / แทรช / เบิร์ส ของเรา" = ของเจ้าของการ์ดที่ใช้เอฟเฟกต์คนเดียว
- ยกเว้นเอฟเฟกต์จั่วการ์ด ("เราจั่วการ์ด N ใบ" และจั่วเพิ่ม/ลดในดรอว์สเต็ปจากการ์ดบนสนาม): เจ้าของเอฟเฟกต์เลือกว่าตัวเองหรือเพื่อนร่วมทีมเป็นคนจั่ว
- "สปิริต/อัลติเมท/เน็กซัส ของคู่แข่ง" = การ์ดบนสนามทั้งทีมคู่แข่ง
- "ไลฟ์ / มือ / เด็ค / รีเสิร์ฟ / แทรช / เบิร์ส ของคู่แข่ง" = ลงผลกับคู่แข่งทั้งสองคน (เช่น ทิ้งเด็คคู่แข่ง 3 ใบ = คนละ 3 ใบ)
  ถ้าเป็นการเลือกการ์ด/คอร์ = เลือกจากของทั้งสองคนรวมกัน
- เจ็มที่ใช้ลดคอสต์ และเงื่อนไขนับเจ็ม/สี (Rush, เจ็ม 3 สี ฯลฯ) = นับจากการ์ดบนสนามทั้งทีม (ใช้ร่วมกัน)
- (ร่าง) เอฟเฟกต์ที่เกิดพร้อมกัน (กติกา 11): ทีมเจ้าของเทิร์นเป็นผู้เรียง · เอฟเฟกต์ของการ์ดใคร คนนั้นเป็นคนเลือกเป้า/ตัวเลือก
