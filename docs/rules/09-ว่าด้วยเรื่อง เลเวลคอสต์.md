ว่าด้วยเรื่อง เลเวลคอสต์
เลเวลคอสต์ (เดิมเขียนว่า คอร์ที่ต้องการในแต่ละเลเวล )
เป็นการบัญญัติศัพท์เพื่อความกระชับในการเขียนข้อความเอฟเฟคนั่นเอง 
เลเวลคอสต์นั้นมีความสำคัญต่อการคงอยู่บนสนามของการ์ดต่างๆ
ทั้งสปิริต อัลติเมท และเนคซัส
เมื่อวางคอร์ไม่พอที่เลเวลหนึ่งต้องการ
ทั้งสปิริต อัลติเมท และเนคซัสเหล่านั้น
จะเกิดเหตุการณ์ที่เรียกว่า “การสูญสลาย” นั่นเอง
ยกตัวอย่างเช่น
1.สปิริตใบนึง มีเลเวลคอสต์ที่เลเวลหนึ่งเป็นสอง
หากเราวางคอร์เพียงเม็ดเดียว สปิริตนี้ก็ไม่อาจคงอยู่ได้และต้องสูญสลายไป
2.สปิริตใบนึง มีเลเวลคอสต์ที่เลเวลหนึ่งเป็นหนึ่ง
ทำการวางคอร์ไว้หนึ่งเม็ด
ถูกเอฟเฟคของอีกฝ่าย “เลเวลคอสต์ของสปิริตทุกใบ +1”
สปิริตนี้ก็ต้องสูญสลายไป เพราะว่า เลเวลคอสต์เปลี่ยนไปเป็นสอง 
คอร์ที่วางไว้เพียงเม็ดเดียวจึงไม่เพียงพอนั่นเอง
3.สปิริตใบนึง มีเลเวลคอสต์ที่เลเวลหนึ่งเป็นหนึ่ง
และเลเวลคอสต์ที่เลเวลสองเป็นสี่
ทำการวางคอร์ไว้สี่เม็ด
ถูกเอฟเฟคของอีกฝ่าย “เลเวลคอสต์ของสปิริตทุกใบ +1”
จะทำให้สปิริตนี้กลายเป็นเลเวลหนึ่งทันที
เพราะ เลเวลคอสต์ที่เลเวลสองต้องการกลายเป็นห้า
แต่ไม่ถึงกับสูญสลาย 
เพราะเลเวลคอสต์ที่เลเวลหนึ่งต้องการคือสอง
ข้อควรทราบ
1.เลเวลคอสต์ที่เลเวลหนึ่งของเนคซัสทุกใบคือ0
ทำให้ไม่ต้องวางคอร์ก็คงอยู่บนสนามได้
2.หากเลเวลคอสต์ของเนคซัสถูกเปลี่ยนแปลง
เนคซัสก็สูญสลายได้เช่นเดียวกับสปิริต
3.ชีลด์ป้องกันการเปลี่ยนแปลงของเลเวลคอสต์ได้
