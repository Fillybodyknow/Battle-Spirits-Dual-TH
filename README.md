# Battle-Spirits-Dual-TH

เว็บแอปเล่นการ์ดเกมสองคน ตามกติกาไทยยุค Double Drive
กติกาอ้างอิงจาก `assets/Battle Spirits — คู่มือกติกาเกมสำหรับวางโครงเว็บแอป.pdf`

## โครงสร้าง

```
packages/
  cards/    schema การ์ด (Zod), ฐานข้อมูลการ์ด, deck validator
            data/sample-set.json = การ์ดตัวอย่างที่ออกแบบเอง ใช้ทดสอบ
            data/sd01.json, sd01-deck.json = Starter Deck 01 (สร้างจาก assets/files/SD1.text)
  engine/   rules engine แบบ pure function: applyAction(state, action, db)
apps/
  web/      UI เล่นสองคนในเครื่องเดียว (React + Vite + Tailwind + Zustand)
```

## คำสั่ง

```sh
npm install
npm run dev        # เปิด UI ที่ http://localhost:5173
npm test           # รันเทสกติกาทั้งหมด
npm run typecheck
npm run cards      # แปลง assets/files/*.text → packages/cards/data/*.json
```

## วิธีเล่นใน UI

- **อ่านการ์ด:** ชี้เมาส์ที่การ์ดใบไหนก็ได้ แผงด้านขวาจะแสดงรายละเอียดเต็ม (คลิกเพื่อปักไว้)
  เอฟเฟกต์ที่ทำงานที่เลเวลปัจจุบันจะสว่าง ป้าย "อัตโนมัติ" = engine ทำให้, "ทำเอง" = ผู้เล่นต้องจัดการเอง
- **เล่นการ์ด:** คลิกการ์ดบนมือ (กรอบเหลือง = เล่นได้) แล้วเลือกอัญเชิญ / Nexus / Magic / Burst
  หน้าต่างอัญเชิญให้เลือกเลเวลที่จะวาง และ Soul Core (เก็บไว้ / ใช้จ่าย / วางบนการ์ด) ระบบจัด Core ให้เอง
  กด "ปรับ Core เอง…" ถ้าต้องการดึง Core จากการ์ดบนสนามมาจ่าย
- **ย้าย Core:** ลาก Core จาก Reserve หรือจากการ์ดไปวางบนการ์ดหรือ Reserve
  ระหว่างลากการ์ดปลายทางจะแสดง Lv/BP หลังวาง และเตือนการ์ดที่จะสูญสลาย
  คลิก Core หลายดวงเพื่อเลือกแล้วลากไปพร้อมกัน (หรือคลิกปลายทาง)
- **โจมตี / ป้องกัน:** คลิกสปิริตที่มีป้าย "คลิกเพื่อโจมตี" (เหลือง) / "คลิกเพื่อป้องกัน" (ฟ้า)
- แถบกลางจอบอกว่าตาใครและต้องทำอะไร ผู้เล่นที่ถือเทิร์นอยู่ด้านล่างเสมอ (ปิดได้ใน ⚙ ตั้งค่า)
- ปุ่ม "↶ ย้อน" ย้อน action ได้ เหมาะกับการทดสอบกติกา
- **ตัดสินใจบนกระดาน:** เลือกเป้าหมาย/ป้องกัน/ทิ้งการ์ด = คลิกการ์ดที่เรืองแสงบนสนามหรือในมือ,
  Evolution / จ่ายคอสต์ = คลิกเลือก Core บนกระดาน แล้วยืนยันที่แถบกลางจอ (ตัวเลือกแบบข้อความเป็นปุ่มในแถบกลางจอ)
  หน้าต่างใช้เฉพาะการเลือกการ์ดจากเด็ค/Trash · **Auto Pass** (เปิดอยู่) Pass/ไม่ป้องกันให้เมื่อไม่มีตัวเลือก
- **เอฟเฟกต์ภาพ:** ป้ายเทิร์น/สเต็ป, cut-in ตอนลงการ์ด X-Rare (คลิกเพื่อข้าม), ลูกศรโจมตี, ป๊อปอัปเมื่อเอฟเฟกต์ทำงาน,
  ตัวเลข Life/BP ลอย · ปิดได้ใน ⚙ ตั้งค่า
