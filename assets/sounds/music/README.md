# เพลงประกอบ (BGM)

วางไฟล์ `.mp3` / `.ogg` / `.m4a` / `.wav` ในโฟลเดอร์นี้ ตั้งชื่อตามตาราง (แนะนำ mp3 128–192 kbps ไฟล์เล็ก)
หลายเพลงต่อช่วง: `duel-1.mp3`, `duel-2.mp3` … เกมสุ่มเพลงใหม่ทุกเกม

| ชื่อไฟล์ | เล่นเมื่อ |
|---|---|
| `duel` | ระหว่างดวลปกติ (หลังฉากโยนเหรียญจบ) |
| `ace` | มีการ์ดระดับ X-Rare ขึ้นไปอยู่บนสนาม ฝ่ายใดก็ได้ (เริ่มตรงจังหวะทุบของ Cut-in · ออกจากสนามหมด = กลับเป็น `duel`) |
| `pinch` | Life ของคู่แข่งเหลือไม่เกิน 2 (เล่นเครื่องเดียว / ผู้ชม = ฝ่ายใดก็ได้) (สำคัญกว่า `ace`) · เริ่มแล้วเล่นต่อจนจบเกม เว้นแต่ Life คู่แข่งกลับมา 4 ขึ้นไป |

- ไม่มีไฟล์ของช่วงไหน = ใช้เพลงช่วงก่อนหน้า (`pinch` → `ace` → `duel`) · ไม่มีไฟล์เลย = เงียบ
- เพลงเล่นวนซ้ำ: ตัดให้ท้ายเพลงต่อกับต้นเพลงได้เนียน (loop ได้)
- เปลี่ยนเพลงแบบ crossfade 1.2 วินาที · จบเกม / ออกจากเกม = เพลงจางหาย
- ปิด/ปรับความดังได้ที่ ตั้งค่า → เสียง → เพลงประกอบ (BGM) (แยกจาก SFX)
